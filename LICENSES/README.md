# Licenses

Full license texts live in this folder. Every content file carries an attribution footer naming the license it is released under.

| File | Applies to |
|---|---|
| `CC-BY-4.0.txt` | All original Codex content, and SRD 5.1-derived material |
| `ORC.txt` | Paizo-derived (PF2e) mechanics |

Those two files must be copied verbatim from the canonical sources below — they are not yet in the repo, and license text must never be paraphrased or retyped.

Canonical sources:

- CC-BY 4.0 — https://creativecommons.org/licenses/by/4.0/legalcode
- SRD 5.1 — https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf
- ORC License — https://azoralaw.com/orclicense/

No Product Identity, ever: no closed-IP monsters, deities, planes, or settings.
