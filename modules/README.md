# Modules

Optional rules dials. Every module is opt-in: core item entries must remain fully usable without any of them.

Planned:

- `quality-tiers.md` — shoddy / common / fine / masterwork
- `wear-and-repair.md` — degradation, maintenance, upgrades
- `haggling.md` — negotiating prices and merchant reactions

Module-dependent text in an item entry is flagged inline, e.g. *(Quality tiers)*.
