# Items

One markdown file per item, with YAML front matter following `docs/item-template.md`.
The filename must match the item's `id` field exactly (e.g. `gear/fine-bedroll.md` → `id: fine-bedroll`).

| Folder | `category:` value | Contents |
|---|---|---|
| `gear/` | `gear` | Adventuring gear and mundane equipment |
| `consumables/` | `consumable` | Alchemical, herbal, and culinary one-shots |
| `weapons/` | `weapon` | Weapons, including regional variants |
| `armor/` | `armor` | Armor and shields |
| `magic/` | `magic` | Magic items (use `rarity`, not `quality`) |

Before adding an item, read `docs/style-guide.md` and `docs/pricing-guide.md`.
